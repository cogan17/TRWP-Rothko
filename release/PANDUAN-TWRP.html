TWRP Recovery

Panduan TWRP
Xiaomi 14T Pro (rothko)

Untuk HyperOS · Dibuat ramah untuk semua orang · oleh Cogan17

Buku ini memandu kamu langkah demi langkah: memasang TWRP, masuk ke TWRP, membuka data, mencadangkan (backup), dan mengembalikan ke semula kalau ada masalah. Tidak perlu jadi ahli — ikuti saja urutannya.

1. Yang perlu disiapkan 2. Memasang TWRP 3. Masuk ke TWRP 4. Membuka data (pola/sandi) 5. Backup data & init_boot 6. Kembali ke stok 7. Ambil log kalau bermasalah 8. Aturan penting

1. Yang perlu disiapkan

  • Komputer Windows + kabel USB yang bagus.
  • Folder platform-tools (berisi adb.exe & fastboot.exe).
  • Bootloader HP sudah ter-unlock.
  • Paket TWRP: ekstrak semua isinya ke dalam folder platform-tools (timpa yang lama). Di dalamnya ada file gambar .img dan beberapa file .bat.
Baterai HP minimal 50% sebelum mulai, biar aman.

2. Memasang TWRP

  1. Matikan HP. Tahan Power + Volume Bawah sampai muncul tulisan FASTBOOT.
  2. Sambungkan HP ke komputer dengan kabel.
  3. Buka folder platform-tools, klik dua kali 1-PASANG-TWRP.bat.
  4. Ikuti petunjuk di layar hitam. Tunggu sampai tertulis BERHASIL — HP akan menyala sendiri ke Android.
Kalau layar menampilkan "HP terdeteksi: rothko" lalu "BERHASIL", pemasangan sukses.

Sudah punya TWRP? Lewat PC: masuk TWRP, colok kabel, klik dua kali 5-UPDATE-LEWAT-TWRP.bat. Tanpa PC: simpan @TWRP_IMG@ di HP, lalu di TWRP pilih Install → Install Image → pilih file itu → Vendor Boot Image → geser. Wajib Vendor Boot, jangan Boot / Init_boot.

3. Masuk ke TWRP

  1. Matikan HP sampai benar-benar mati.
  2. Tahan Volume Atas + Power bersamaan.
  3. Saat logo Mi muncul, lepas tombol Power tapi tahan terus Volume Atas sebentar, sampai TWRP terbuka.
Masuk TWRP harus dari kondisi HP mati + tombol, bukan lewat perintah "reboot recovery".

4. Membuka data (pola / sandi)

Saat masuk, TWRP minta membuka kunci data:

  • Pengguna utama (0): gambar pola yang sama seperti di layar kunci HP — sekali saja, teliti. Kalau benar, semua data (Download, DCIM, dll) langsung terlihat.
  • XSpace / Ruang Kedua (999): ini profil terpisah dengan sandi sendiri. Masukkan sandinya kalau kamu memakainya; kalau tidak, lewati saja — data utama tetap terbuka.
Jangan coba berkali-kali kalau lupa. Salah berulang bisa mengunci sementara (sistem keamanan). Cukup sekali kalau yakin.

5. Backup data & init_boot

Cadangkan file pribadi (Download, DCIM, foto):

  • Paling mudah: lewat Android biasa, colok kabel, pilih Transfer File, salin ke PC.
  • Lewat TWRP: menu File Manager → pilih folder → salin ke penyimpanan OTG.

Cadangkan partisi penting (init_boot, boot, dll):

  1. Di TWRP, buka menu Backup.
  2. Centang partisi yang mau dicadangkan (mis. Boot, Init_boot, Super).
  3. Geser untuk memulai. Hasilnya tersimpan di folder TWRP/BACKUPS.
Simpan hasil backup ke PC/flashdisk juga, biar aman kalau HP bermasalah.

6. Kembali ke stok (kalau mau batal)

Mau menghapus TWRP dan kembali seperti semula? Data tidak akan dihapus.

  1. Masuk mode FASTBOOT: dari HP mati, tahan Power + Volume Bawah.
  2. Colok kabel, lalu jalankan 2-KEMBALIKAN-STOK.bat.
  3. Tunggu sampai BERHASIL. HP menyala ulang ke HyperOS normal.

Tanpa PC (kalau TWRP masih bisa dibuka): TWRP → Install → Install Image → @STOCK_IMG@ → Vendor Boot Image → geser → Reboot → System.

Kalau HP sempat bootloop (muter di logo Mi), ini cara memperbaikinya: paksa mati (tahan Power ~15 detik), masuk FASTBOOT, jalankan 2-KEMBALIKAN-STOK.bat.

7. Ambil log kalau butuh bantuan

  • TWRP jalan tapi ada masalah (sentuh, dekripsi, dll): jalankan 3-AMBIL-LOG.bat.
  • HP bootloop / tidak mau boot: masuk TWRP langsung dari bootloop (Volume Atas + Power, jangan matikan paksa), lalu jalankan 4-LOG-BOOTLOOP.bat.

File log tersimpan di folder Downloads di PC. Kirim isinya ke pembuat TWRP — terutama recovery.log atau console-ramoops-0.

8. Aturan penting (baca ini!)

JANGAN pilih "Format Data" atau "Wipe" sembarangan — itu menghapus SEMUA foto & data. Hanya lakukan kalau kamu benar-benar mau menghapus total.
  • Selalu backup data penting sebelum bereksperimen.
  • Pasang hanya file TWRP untuk rothko (14T Pro) — jangan dari HP lain.
  • Kalau modul KernelSU mati setelah bootloop, itu pengaman otomatis — nyalakan lagi di aplikasi KernelSU → Modul → reboot.
